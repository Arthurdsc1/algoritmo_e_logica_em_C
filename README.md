# Algoritmos e Lógica de Programação em C

Exercícios resolvidos em **C** do curso **Algoritmos e Lógica de Programação**, do professor **Nélio Alves** (Udemy, 31 horas).

O repositório reúne os problemas que resolvi durante o curso, organizados em um arquivo `.c` por exercício.

## Conteúdo abordado

- Entrada e saída de dados
- Estruturas condicionais 
- Estruturas de repetição 
- Vetores
- Matrizes

## Exercícios

| Arquivo | Tema |
|---|---|
| `soma.c` | Soma de valores |
| `celsius.c` | Conversão de temperatura |
| `retangulo.c` | Cálculos com retângulo |
| `terreno.c` | Cálculos com terreno |
| `media.c` | Cálculo de média |
| `notas.c` | Processamento de notas |
| `baskara.c` | Raízes de equação do 2º grau (fórmula de Bhaskara) |
| `menor_de_tres.c` | Menor entre três valores |
| `crescente.c` | Ordem crescente |
| `idade.c` | Exercício com idades |
| `media_idade.c` | Média de idades |
| `alturas.c` | Exercício com alturas |
| `soma-impares.c` | Soma de números ímpares |
| `tabuada.c` | Tabuada |
| `numeros_negativos.c` | Números negativos |
| `vetor.c` | Operações com vetor |
| `matriz.c` | Operações com matriz |
| `diagonal_negativos.c` | Diagonal da matriz e valores negativos |
| `soma_linhas.c` | Soma das linhas de uma matriz |

## Como executar

É necessário ter um compilador C instalado, como o [GCC](https://gcc.gnu.org/).

```bash
# compilar
gcc nome_do_arquivo.c -o programa

# executar (Linux/macOS)
./programa

# executar (Windows)
programa.exe
```

Exemplo:

```bash
gcc tabuada.c -o tabuada
./tabuada
```
